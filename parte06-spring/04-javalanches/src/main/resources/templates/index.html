JAVA LANCHES

O sistema JAVA LANCHES foi desenvolvido para facilitar o gerenciamento interno da lanchonete. Com ele, é possível cadastrar usuários, clientes, categorias e lanches de forma simples e organizada, centralizando as informações e tornando a administração do negócio mais eficiente, prática e segura.

Vamos cadastrar um cliente? Ou uma Categoria para começar!
